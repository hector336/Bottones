GRID EN CSS

REGRESAR

1. INTRODUCCIÓN


CSS Grid es un sistema de diseño que permite organizar elementos dentro de filas y columnas. Para utilizarlo se aplica display: grid al contenedor. Grid permite controlar fácilmente el número de columnas y filas, el espacio entre los elementos y la posición que ocupa cada elemento. Algunas propiedades importantes son grid-template-columns, grid-template-rows, gap y grid-column. Es muy útil para crear estructuras ordenadas y organizar diferentes elementos de una página web.
