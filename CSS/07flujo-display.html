FLUJO NORMAL Y DISPLAY

REGRESAR

1. INTRODUCCIÓN


El flujo normal en CSS es la forma en la que los elementos HTML se acomodan automáticamente dentro de una página. Los elementos se colocan siguiendo el orden en el que aparecen en el código HTML. La propiedad display permite cambiar la forma en la que un elemento se comporta dentro de este flujo. Algunos valores importantes son block, que hace que el elemento ocupe todo el ancho disponible; inline, que permite que varios elementos estén en la misma línea; inline-block, que combina características de ambos; y none, que permite ocultar un elemento de la página.
