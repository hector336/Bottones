POSICIONAMIENTO EN CSS

REGRESAR

1. INTRODUCCIÓN


El posicionamiento en CSS permite controlar la ubicación de los elementos dentro de una página web. La propiedad position puede utilizar diferentes valores como static, relative, absolute, fixed y sticky. Static es la posición normal de los elementos, relative permite mover un elemento tomando como referencia su posición original, absolute permite posicionar un elemento respecto a su contenedor, fixed mantiene un elemento fijo en la pantalla y sticky permite que un elemento se comporte de forma normal hasta llegar a una posición determinada y después permanezca visible.
