ANIMACIONES EN CSS

REGRESAR

1. INTRODUCCIÓN


Las animaciones en CSS permiten cambiar gradualmente los estilos de un elemento durante un determinado periodo de tiempo. Para crear una animación se utiliza la propiedad animation y la regla @keyframes, que permite definir los cambios que tendrá el elemento. Algunas propiedades importantes son animation-name, animation-duration, animation-delay, animation-iteration-count y animation-direction. Las animaciones pueden utilizarse para mover, cambiar de tamaño, rotar o modificar los colores de los elementos de una página web.
