1. INTRODUCCIÓN


Bootstrap es un framework que facilita el desarrollo y diseño de páginas web utilizando clases CSS y componentes prediseñados. Permite crear páginas adaptables a diferentes tamaños de pantalla y proporciona elementos como botones, tarjetas, alertas, formularios y sistemas de columnas. Para utilizar Bootstrap en un documento HTML se puede incluir su archivo CSS mediante una etiqueta link. Después es posible utilizar sus clases directamente en los elementos HTML para aplicar diferentes estilos y componentes.
