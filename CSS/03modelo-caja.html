El modelo de caja (Box Model) en CSS es el concepto fundamental sobre el que se construye el diseño y la maquetación web. Básicamente, el navegador envuelve cada elemento HTML en una caja rectangular. Esta caja está compuesta por cuatro áreas principales, desde adentro hacia afuera: contenido (Content), que es el corazón de la caja donde viven el texto, las imágenes u otros elementos y cuyo tamaño se controla con las propiedades width y height; relleno (Padding), que es el espacio transparente que rodea el contenido y lo separa del borde; borde (Border), que es la línea que envuelve el relleno y el contenido y cuyo grosor, estilo y color se pueden modificar; y margen (Margin), que es el espacio transparente más externo y sirve para separar la caja de otros elementos que la rodean.
