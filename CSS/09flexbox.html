REGRESAR

1. INTRODUCCIÓN


Flexbox es un sistema de diseño de CSS que permite organizar y distribuir elementos fácilmente dentro de un contenedor. Para utilizarlo se aplica display: flex al elemento que contiene los elementos que queremos organizar. Flexbox permite controlar la dirección, alineación, separación y distribución de los elementos. Algunas propiedades importantes son flex-direction, justify-content, align-items, gap y flex-wrap. Es muy útil para crear diseños ordenados y adaptables a diferentes tamaños de pantalla.
